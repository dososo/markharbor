# Support

## Before Opening an Issue

Please check:

- [README.md](README.md)
- [docs/INSTALL.md](docs/INSTALL.md)
- [docs/PRIVACY.md](docs/PRIVACY.md)
- [docs/ROADMAP.md](docs/ROADMAP.md)

## Good Support Requests Include

- MarkHarbor version.
- Browser and OS.
- Whether you installed from GitHub Releases or built from source.
- Steps to reproduce.
- Relevant counts from `export-report.json`.

Please remove private bookmark text, screenshots, and exported files before posting.

## Security or Privacy Issues

Do not open a public issue. See [SECURITY.md](SECURITY.md).

## 中文说明

提问前请先查看 README、安装说明、隐私说明和路线图。提交问题时请附上版本、浏览器、系统、复现步骤和必要的导出统计，并移除私人书签内容。
