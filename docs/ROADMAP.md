# Roadmap

This roadmap is intentionally conservative. MarkHarbor prioritizes reliable local export over cloud features or broad scraping.

## Near Term

- Improve manual Chrome validation coverage.
- Add more real-world X Bookmark DOM fixtures.
- Improve X Article body image ordering when X changes virtualized rendering.
- Add clearer troubleshooting docs for common install and permission issues.

## Later

- Optional Obsidian import presets.
- Better export preview before downloading.
- More resilient parser diagnostics in `export-report.json`.
- Optional browser-side search within collected bookmarks before export.

## Not Planned

- Cloud sync.
- Hosted account system.
- Reading X passwords or cookies.
- Calling undocumented X internal APIs.
- Downloading X videos.
- Fetching arbitrary external article full text by default.
- Team workspace features.

## 中文路线图

短期优先提高真实 Chrome 验证覆盖、补充 X DOM 样本、增强 X Article 图片顺序稳定性和安装排障文档。暂不计划云同步、账号系统、读取 cookie、调用未公开 API、下载视频或默认抓取外部文章全文。
