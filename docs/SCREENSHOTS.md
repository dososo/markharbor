# Screenshot Checklist

Use this checklist before a public announcement, README image update, or Chrome Web Store submission.

## Required Screenshots

| File | Size | Purpose |
| --- | --- | --- |
| `docs/assets/popup-ready.png` | 1280 x 800 or similar | MarkHarbor opened on X Bookmarks before collection. |
| `docs/assets/popup-collecting.png` | 1280 x 800 or similar | Collection in progress with visible status. |
| `docs/assets/export-zip-structure.png` | 1280 x 800 or similar | Export zip showing Markdown, JSON, CSV, HTML, and attachments. |
| `docs/assets/obsidian-index.png` | 1280 x 800 or similar | `X Bookmarks Index.md` opened in Obsidian. |
| `docs/assets/obsidian-note.png` | 1280 x 800 or similar | Single bookmark Markdown note with text and images. |

## Capture Rules

- Do not expose private bookmarks, DMs, account information, or paid content.
- Use demo data or redact sensitive text.
- Keep browser zoom at 100%.
- Prefer light mode for readability unless showing Obsidian dark mode intentionally.
- Verify text is readable at GitHub README size.

## Social Preview

`docs/assets/markharbor-social-preview.png` can be used as the GitHub repository social preview image. `docs/assets/markharbor-social-preview.svg` is the editable source. GitHub social previews are configured manually in repository settings.
